# Экспедиторская — лендинг

Статический одностраничный сайт: HTML, CSS и немного JavaScript без сборки и зависимостей.
Сценарий страницы и тексты — из `demo/src/BasisCore/docs/Landing/`.

## Структура

```
public/                  всё, что публикуется
  index.html             страница
  assets/css/tokens.css  цвета, шрифты, отступы (токены)
  assets/css/styles.css  оформление блоков
  assets/js/main.js      меню, вкладки, просмотр экранов
  assets/img/            экраны системы (WebP) и значок
  assets/fonts/          IBM Plex Sans (вариативный) и IBM Plex Mono, кириллица и латиница
diagrams/build.py         диаграммы: источник SVG, вставляет их в index.html и пишет diagrams/*.html
.github/workflows/pages.yml  публикация public/ на GitHub Pages
```

Локально сайт открывается по адресу http://demo-landing.test (Herd, конфиг
`demo-landing.test.conf`).

## Перед публикацией

1. **Форма.** Встроена Яндекс Форма с автоматической высотой iframe.
   Редактор и ответы: https://forms.yandex.ru/admin/6ac1ee33068ff02a82f91c3f/edit.
   Поля и настройки меняются в Яндекс Формах; свой обработчик отправки не нужен.
2. **Согласие на обработку данных, контакты и реквизиты.** Места отмечены в `index.html`
   комментариями `TODO перед публикацией`.
3. **Экраны.** Снимки сняты с локального демо (`demo.test`), данные демонстрационные.
   Перед публикацией стоит просмотреть их ещё раз на предмет названий и сумм.
4. **Open Graph.** Заменить `og:image` на абсолютный адрес после выбора домена.
5. **Ссылка на ГОСТ.** Глава про ГОСТ Р 72552–2026 и ответ в вопросах ссылаются на карточку
   стандарта на сайте Росстандарта (`protect.gost.ru`). Перед публикацией открыть ссылку и
   убедиться, что она ведёт на нужный документ.
6. **Экран задачи.** Снимок в главе про задачи — форма новой задачи, заполненная на демо и
   не сохранённая: в демо-базе задач нет. Карточку задачи с обсуждением можно снять, когда
   появятся демонстрационные данные.

7. **Автопривязка писем.** Глава про архив переписки описывает поиск записи по номерам в теме,
   тексте и именах вложений. В `../demo` этого проектного правила нет (есть в `../ssb2` и
   `../basis`): перед публикацией убедиться, что оно входит в поставку «Экспедиторской».
8. **Цена и «без подписок».** Блок про vendor lock-in говорит, что ограничений по количеству нет,
   а ответ «Сколько стоит система?» упоминает число пользователей. Согласовать формулировки.

## GitHub Pages

Все пути в странице относительные, поэтому сайт работает и в корне домена, и в подкаталоге
`https://<user>.github.io/<repo>/`. Публикация: запушить репозиторий, в настройках включить
Pages с источником «GitHub Actions» — workflow выложит каталог `public/`.
